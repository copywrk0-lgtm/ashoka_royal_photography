# Media upload note

The supplied project includes 47 JPG images and 5 MP4 videos.

GitHub's browser uploader has a per-file size limit that the 27.5 MB film file exceeds. The source project can be committed normally, but the large video assets should be added through Git LFS or Git's command-line upload rather than the browser drag-and-drop uploader.

See the local project archive supplied with this build for the complete media set.
